## 🚀 Technologies Used
**HTML5 (Estrutura Semântica):** Construção da fundação estrutural e da árvore de acessibilidade da página, garantindo indexação otimizada para motores de busca e legibilidade nativa.
* **CSS3 (Estilização Avançada):** Camada de apresentação visual isolada, utilizando recursos modernos de posicionamento e animações que rodam direto na unidade de processamento gráfico para transições fluidas.
* **JavaScript Vanilla (Puro):** Motor de interatividade do sistema executado sem intermediários ou dependências externas, reduzindo o tempo de carregamento e garantindo controle cirúrgico do comportamento do site.
* **Otimização e Performance do DOM:** Gerenciamento inteligente e performático da árvore de elementos da tela, minimizando atualizações repetidas para poupar a memória do dispositivo e evitar travamentos.
* **Robustez na Integração com APIs RESTful:** Mecanismo moderno para o envio e recebimento de dados assíncronos em tempo real, conectando o cliente ao servidor de forma segura e resiliente a falhas.
* **Estados de Carregamento (UX):** Gerenciamento visual de feedbacks (como sinalizadores de espera e alertas de erro), mantendo o usuário informado durante as operações enquanto isola a lógica de negócios das alterações visuais para facilitar futuras manutenções.
